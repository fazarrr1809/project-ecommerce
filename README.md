# Flutter E-Commerce - Clean Architecture

Aplikasi E-Commerce Flutter yang dibangun dengan menerapkan **Clean Architecture** dan metode **Test-Driven Development (TDD)**.

## 🚀 Fitur Utama
* **Clean Architecture:** Pembagian kode ke dalam lapisan Data, Domain, dan Presentation.
* **TDD (Test-Driven Development):** Dilengkapi dengan unit testing untuk memastikan keandalan kode.
* **State Management:** Menggunakan pola yang efisien untuk menangani alur data.
* **UI Responsif:** Desain modern yang nyaman digunakan di berbagai ukuran layar.

## 🏗️ Struktur Arsitektur
Proyek ini mengikuti prinsip *Clean Architecture* dari Uncle Bob:
- **Domain:** Berisi *Entities*, *Use Cases*, dan *Repository Interfaces* (Inti bisnis).
- **Data:** Berisi implementasi repository, model data, dan sumber data (API/Local).
- **Presentation:** Berisi UI (Widget), Page, dan logika State Management.
